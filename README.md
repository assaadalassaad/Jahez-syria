# جاهز — مشروع الويب وتهيئة APK

هذه حزمة مصدر أولية لمشروع «جاهز». لا تتضمن APK جاهزاً؛ يُبنى ملف APK من خلال GitHub Actions.

## مهم قبل النشر
1. لا تستبدل موقع Vercel الحالي قبل حفظ نسخة احتياطية.
2. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (لا ترفع ملف ZIP نفسه فقط).
3. في Supabase افتح SQL Editor ونفّذ `supabase/schema.sql`.
4. افتح الموقع بعد نشره، وأدخل Project URL والمفتاح العام `anon` أو `publishable` من إعدادات Supabase. لا تستخدم `service_role` داخل الموقع.
5. اختبر إنشاء إعلان وطلب خدمة من جهازين مختلفين.

## بناء APK من GitHub
بعد رفع الملفات إلى الفرع `main` أو `master`، افتح تبويب Actions وشغّل `Build Android APK` أو انتظر تشغيله تلقائياً. عند نجاح المهمة، افتح تشغيل المهمة ثم نزّل Artifact باسم `jahez-debug-apk`، وفك ضغطه لتحصل على `app-debug.apk`.

## ملاحظات
- هذا APK تجريبي للتثبيت والاختبار، وليس إصداراً موقّعاً للنشر على المتجر.
- قاعدة البيانات المشتركة تتطلب إعداد Supabase وتنفيذ ملف SQL.
- قبل إطلاق المنصة للعامة، يلزم تحسين المصادقة ومراجعة سياسات الأمان والخصوصية ومنع إساءة الاستخدام.
